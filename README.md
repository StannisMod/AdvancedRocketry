# Advanced Rocketry - Reworked

A maintained fork of **Advanced Rocketry** for **Minecraft 1.12.2**.

This project continues development of the original Advanced Rocketry mod with ongoing fixes, improvements, and quality-of-life updates for modern 1.12.2 modpacks.

---

## Download

Get the mod on CurseForge:  
**[Advanced Rocketry - Reworked](https://www.curseforge.com/minecraft/mc-mods/advanced-rocketry-2)**

---

## About

**Advanced Rocketry - Reworked** exists to keep Advanced Rocketry alive and actively maintained for the community.

The goal of this fork is to improve stability, expand usability for pack developers and players, and continue refining one of the most ambitious space-tech mods for Minecraft 1.12.2.
